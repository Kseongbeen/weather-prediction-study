# 🌦️ 다중 기상 예보 앙상블 기반 기온 예측 오차 최소화 연구

기상청, 아큐웨더, 메테오블 등 다중 기상 예보 채널의 단일 예측 온도 데이터를 통합 수집하고, 다중 선형 회귀와 가중 보팅 앙상블을 비교하여 실제 관측 온도와의 오차(RMSE, MAE)를 보정한 연구 프로젝트입니다.

## ✨ 연구 프로세스 및 모델링

1. **시계열 예측 데이터 정제 및 동기화**
   * 수집 주기가 불규칙하거나 포맷이 다른 6개 예보 서비스의 단기 예측 온도를 날짜/시간축 단위로 정밀 조인(Outer Join) 및 결측치 보간.
2. **채널별 예측 편향(Bias) 산출**
   * 단일 기상 예보 서비스들이 갖는 계절별, 시간대별 고유 오차 특성 분석.
3. **가중 선형 회귀(Weighted Linear Regression) 모델**
   * 각 예보 채널의 과거 예측 기여도(신뢰 지표)를 가중치 파라미터 $\beta_i$로 산정하여 수학적 최적 기온 보정식 수립.
4. **가중 보팅 앙상블 비교**
   * 사이트별 성능 기반 가중치로 예측을 합치는 가중 보팅 앙상블을 비교. 테스트 RMSE 2.239로, 오차가 큰 사이트의 노이즈 때문에 오히려 성능이 낮았음.
5. **예측 오차 최소화 성과**
   * 다중 선형 회귀가 테스트 RMSE **1.839**로 가장 좋았고, 단일 사이트 중 최고였던 기상청(1.960) 대비 **약 6.2% 개선**.
